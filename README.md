# Particle Image Reveal Animation

A Python script that turns any image into a "particles flying in to reveal
a glowing neon drawing" animation — the kind of effect used in coding/POV
reels — and renders it out as an MP4 you can drop straight into a video
editor or post as-is.

> This code was generated by an AI (Claude).

## What it does

You give it a source image. It:

1. Detects the image's outlines (edges) and treats them as bright, thick,
   heavily-saturated "neon" particles — these are what make the drawing
   readable and give it that glowing line-art look.
2. Samples a much sparser set of particles from the interior of the shapes
   ("fill" particles) and keeps them dim, so the inside reads as soft
   color/shading instead of a flat block.
3. Scatters a layer of small "sparkle dust" particles in a fixed neon
   palette (white, cyan, magenta, gold, violet) around the outlines, which
   fade and twinkle in place rather than flying — this is the glitter halo
   you see drifting around the subject.
4. Animates every particle flying in from a random scattered start position
   (or exploding outward from the center, if you switch modes) to its final
   position, with staggered timing so they don't all arrive at once.
5. Applies a two-pass glow (bloom): one tight, crisp pass for a glowing
   core, and one soft, wide pass for the ambient halo — combined, this is
   what makes the result look like actual neon instead of a blurry haze.
6. Renders everything frame-by-frame and encodes it into an MP4 with
   ffmpeg.

## How it works, step by step

1. **Load and resize** — the source image is loaded and scaled to fit the
   output canvas while keeping its aspect ratio.
2. **Find the background** — instead of assuming the background is pure
   black, the script auto-detects the actual brightness cutoff between
   background and subject for that specific image (Otsu's method), so it
   also works on screenshots or images with a dark-gray background.
3. **Split into edges and fill** — a Canny edge detector finds the outlines
   of the subject. Every foreground pixel is then bucketed into "edge" or
   "fill."
4. **Sample particles from each bucket** — edges are sampled at close to
   full density (few are dropped); fill pixels are sampled much more
   sparsely, since they're only there for subtle shading.
5. **Build the sparkle layer** — a separate set of particles is placed
   with small random offsets around the edge particles' positions, colored
   from a fixed neon palette rather than the source image's own colors.
6. **Boost the colors** — edge particles get their saturation and
   brightness pushed hard toward vivid neon; fill particles get a smaller
   boost so they stay in the background.
7. **Animate** — each particle gets a random starting position and a
   randomized delay (stagger), then eases from its start to its final
   position over the "fly-in" duration. Sparkle particles don't move; they
   just fade and flicker into existence.
8. **Glow pass** — after each frame is drawn, two Gaussian blurs are
   applied to the brightest pixels only (one tight, one soft) and screen-
   blended back onto the frame, producing the neon bloom.
9. **Encode** — all rendered frames are stitched into an MP4 with ffmpeg.

## Requirements

- Python 3
- `numpy`, `matplotlib`, `Pillow`, `scipy`
- `opencv-python` (for edge detection — the script falls back to a simpler
  gradient-based edge estimate if it isn't installed)
- `scikit-image` (optional — used for more accurate background detection)
- `ffmpeg` installed and available on your system PATH

Install the Python packages with:

```bash
pip install numpy matplotlib Pillow scipy opencv-python scikit-image
```

## Usage

1. Put your source image in the project folder and update `SOURCE_IMAGE`
   at the top of the script to point to it.
2. Adjust any of the settings in the `CONFIG` section — canvas size,
   animation length, particle density, colors, glow strength, etc. Each
   setting has a comment explaining what it does.
3. Run the script:

```bash
python particle_reveal_v2.py
```

4. Find your rendered video at the path set in `OUTPUT_VIDEO` (default:
   `particle_reveal.mp4`).

## Notes

- You need to supply your own source image. This script does not include
  or generate any copyrighted artwork — point it at any image you have
  the rights to use.
- Rendering time scales with particle count, canvas resolution, and video
  length. Lower `EDGE_CEILING` / `FILL_CEILING` / `SPARKLE_COUNT` or the
  frame rate if renders are too slow on your machine.
